# Princípios do MotionLab

Os princípios representam os valores fundamentais do MotionLab.

Eles orientam decisões de arquitetura, desenvolvimento, experiência do usuário e evolução do produto.

Todo documento do projeto deve estar alinhado a estes princípios.

Os princípios possuem prioridade sobre decisões técnicas, padrões de implementação e componentes do Design System.

Sempre que houver conflito entre uma implementação e um princípio, o princípio deve prevalecer.
