# Princípios do MotionLab

Os Princípios do MotionLab representam os valores fundamentais que orientam o desenvolvimento do produto.

Eles estabelecem como pensamos, projetamos, implementamos e evoluímos o sistema.

Enquanto a Arquitetura define como o sistema é organizado e o Design System define como a interface é construída, os Princípios definem os valores que orientam todas essas decisões.

Sempre que existir conflito entre uma decisão técnica e um princípio, o princípio deve prevalecer.

Os princípios são permanentes e independem da tecnologia utilizada.
